متجر Y2R - تشغيل سريع
1) ثبّت Node.js من موقع nodejs.org (مرة واحدة فقط).
2) اضغط مرتين على INSTALL-AND-RUN.bat  (يثبّت المكتبات ويشغّل المتجر ويفتح المتصفح).
   أو في نافذة الأوامر داخل المجلد:  npm install  ثم  npm run dev
3) المتجر:   http://localhost:3000
   الطلبات:  http://localhost:3000/admin.html  (المفتاح يظهر في نافذة الأوامر، أو ضعه في ملف .env باسم ADMIN_KEY)
لتغيير الأحذية والأسعار: عدّل data/products.json وضع الصور في public/images/shoes
الطلبات تُحفظ في data/demo-orders.json (وضع تجريبي، لا يوجد دفع حقيقي).

صفحة المنتج: اضغط على أي حذاء لتفتح صفحته الكاملة (عنوانها مثل http://localhost:3000/#/product/3).
لإضافة وصف خاص لحذاء: أضف "description" في data/products.json لذلك الحذاء.

الأسعار بالدينار الجزائري (دج): عدّلها في data/products.json (الحقل price).
عرض 3D: مكتبة Three.js داخل public/vendor (لا تحتاج إنترنت). اسحب لتدوير الحذاء، انقر مرتين للتكبير.
الألوان: صور حقيقية لكل لون داخل public/images/colors (مولّدة تلقائيًا). يمكنك استبدال أي صورة بصورة حقيقية بنفس الاسم.
